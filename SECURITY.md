# Security policy

Report suspected vulnerabilities privately using
[GitHub private vulnerability reporting](https://github.com/pacificao/agrarian/security/advisories/new).
Do not post exploitable details in public issues or pull requests.

Include the affected version or full commit ID, platform, and impact. Never
include wallet backups, seed phrases, private keys, credentials, or personal
information. Use a disposable test wallet or regtest for verification.

Official desktop binaries, when available, will be distributed through
[GitHub Releases](https://github.com/pacificao/agrarian/releases). Verify the
signed checksum manifest before running a download. Development snapshots are
not supported releases.
